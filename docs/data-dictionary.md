# Data dictionary

Source records contain stable `source_id`, title, document type, revision, effective date, locator, lifecycle status, architecture, text, constraints, provenance, validation outcome, and optional structured project parameters. Application records use canonical kW, °C, L/min, kPa, V, Hz, and mm units after normalization. All identifiers begin with fictional `NTS`, `APP`, or `PRJ` namespaces.
